# My ToDo App

A beautiful, minimal, anime-style todo application built with React and Tauri.

## Features

-  Beautiful UI with Gifs especially Ghibli
-  Sheyla messages 
-  Drag and drop to reorder tasks
-  Auto-save to local storage
-  Add and manage tasks
-  Mark tasks as done
-  Edit tasks (double-click to edit)
-  Delete tasks

## Getting Started

### Development

```bash
npm run dev
```

Runs the app in development mode with hot reload.

### Build

```bash
npm run build
```

Builds the React app for production.

### Build Tauri App

```bash
npm run tauri build
```

Creates the desktop application executable.

## How to Use

1. **Add a task**: Type in the input field and click "Add" or press Enter
2. **Complete a task**: Click the checkbox to mark as done
3. **Edit a task**: Double-click on the task text
4. **Delete a task**: Click the "X" button
5. **Reorder tasks**: Drag and drop tasks to change their order

## Technologies

- React
